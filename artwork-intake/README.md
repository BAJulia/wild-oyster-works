# Artwork intake

Drop original photographs here for the **Artwork Curator** to work with.

- Use a subfolder per piece if you can, e.g. `artwork-intake/blue-dresser/`. If several pieces are mixed together, the curator will ask which photos belong together.
- Originals are **never modified, moved or deleted**. The curator makes resized web copies in `public/images/`.
- Everything in this folder (except this README) is **excluded from Git**, so originals, which can contain the photo's GPS location, are never uploaded to the public repository.
- Phone photos in HEIC format can't be processed; export them as JPEG first (on iPhone: Settings → Camera → Formats → Most Compatible, or share/export as JPEG).
